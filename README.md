# Plan Zajęć dla Zuzi 🩺❤️

Dedykowana aplikacja internetowa do wpisywania i zarządzania planem zajęć oraz bloków klinicznych na studiach medycznych.

## Funkcje
- 📅 **Widok miesięczny, tygodniowy i agenda**
- ⚡ **Generator bloków wielodniowych** (wypełnianie całego tygodnia zajęć klinicznych jednym kliknięciem)
- 📍 **Zarządzanie salami i szpitalami** (Banacha, Ciołka, Litewska, CBI, CD i inne)
- 🎨 **Kolorystyczne oznaczanie przedmiotów**
- 📲 **Eksport do Kalendarza Apple / Google (.ics)**
- 💾 **Zapis w przeglądarce i kopie zapasowe JSON**
